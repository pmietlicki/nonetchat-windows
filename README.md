# NoNetChat — Windows native code

Native Windows components of NoNetChat, the nearby messenger that works offline.
NoNetChat code is licensed under Apache-2.0; third-party licenses are retained
in REUSE.toml, LICENSES/ and the original source notices.

To verify release 0.3.0, check SOURCE.json: sourceRevision identifies the
source snapshot and each listed sha256 authenticates an exported file. On a
machine with the FSFE REUSE tool installed, run `reuse lint` to check licensing.
Application downloads and checksums: https://nonetchat.com/en/#downloads
